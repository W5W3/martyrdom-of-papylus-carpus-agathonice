# The Martyrdom of Papylus, Carpus, and Agathonice

A short interactive story, made in [Twine](https://twinery.org/) (Harlowe 3.3.9), retelling the second-century
martyrdom at Pergamum. Follow Papylus, Carpus, or Agathonice and choose how each meets the proconsul's demand.

**Play it:** https://w5w3.github.io/martyrdom-of-papylus-carpus-agathonice/

## Features

- Pixel-art scenes in the style of 1980s PC games, drawn by the game itself (no image files needed)
- Footnotes and citations that can be switched on or off at any point (the Notes button, or the N key)
- Separate endings lists for each tradition of the account, kept between plays
- Number keys 1–9 choose options

## Files

| File | What it is |
|---|---|
| `index.html` | The published game (what GitHub Pages serves) |
| `martyrdom.twee` | The source, for importing into Twine (Library → Import) |

Inside the story, the **Author Guide** passage explains how to add footnotes, sources, pictures and endings.

## Updating the site

1. Edit the story in Twine.
2. **Build → Publish to File**, and save it over `index.html` in this folder.
3. Optionally **Build → Export as Twee** and save over `martyrdom.twee`, so the source stays in step.
4. Commit and push; GitHub Pages updates within a minute or two.

## Sources

Herbert Musurillo, ed. and trans., *The Acts of the Christian Martyrs* (Oxford: Clarendon Press, 1972);
Eusebius, *Ecclesiastical History* 4.15.48. The icon shown in the game is from the Orthodox Church in America.
